# Release scope

| Included | Not included |
|---|---|
| Complete source code of the planner (segmentation training and inference, geometry, virtual deployment, ranking) | Patient images, labels, case lists or any derived per-patient record |
| Statistical analysis code of the study | Checkpoints trained on clinical data |
| Configuration files and the transcribed selection table | Manufacturer documents |
| Synthetic phantom generator, tests and a demo | Results of the accompanying article (reported in the article) |

Trained weights may be shared on request after publication, subject to the data agreements of the participating
centres.
